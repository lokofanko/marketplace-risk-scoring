# 🛡️ Classified Ads Protection Platform

Проект представляет собой платформу для объявлений с интегрированной системой машинного обучения для фильтрации скама.

## 🚀 Быстрый старт

### 1. Настройка ML-сервиса (Docker)
Для работы системы анализа контента необходимо запустить ML-модуль. Убедитесь, что **Docker** запущен.

```bash
cd ml_service
docker build -t risk_ml .
docker run -p 8001:8000 risk_ml
```
*ML-сервис будет доступен на порту `8001`.*

### 2. Настройка Backend (Django)
Откройте второй терминал и перейдите в папку бэкенда:

```bash
cd backend
```

#### Настройка окружения:
1. Выберите интерпретатор Python: `Ctrl + Shift + P` —> **Select Python Interpreter**.
2. Выберите созданное ранее окружение: `Python 3.8 (projectenv)`.

#### Конфигурация почты:
Для корректной отправки уведомлений о скаме необходимо настроить SMTP:
1. Откройте файл: `backend/classifiedads/settings.py`.
2. Перейдите к **строке 191**.
3. Вставьте **пароль для внешних приложений** от вашей почты Mail.ru.
   > 💡 Получить его можно в настройках безопасности почтового ящика Mail.ru.

## 🛠 Разработка и запуск

### Основная логика
Весь основной функционал обработки объявлений и взаимодействия с ИИ находится здесь:
📂 `backend/ads/views.py`

### Создание администратора
Для доступа к панели управления создайте суперпользователя:
```bash
python manage.py createsuperuser
```
*Следуйте инструкциям в терминале для ввода логина и пароля.*

### Запуск сервера
```bash
python manage.py runserver
```

## 🧪 Тестирование сценария

Чтобы проверить работу системы защиты, выполните следующие шаги:

1. **Регистрация:** Перейдите на сайт и создайте нового (обычного) пользователя.
2. **Публикация:** Попробуйте опубликовать объявление, содержащее подозрительный или скам-контент.
3. **Проверка:** 
   - Система автоматически проанализирует текст через ML-сервис.
   - Если контент распознан как скам, на **админскую почту** должно прийти уведомление.
